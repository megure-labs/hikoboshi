# Demo data attribution

The demo uses the following Protein Data Bank entries:

- [1HBS](https://www.rcsb.org/structure/1HBS)
- [1IGY](https://www.rcsb.org/structure/1IGY)
- [1MBA](https://www.rcsb.org/structure/1MBA)
- [1MBO](https://www.rcsb.org/structure/1MBO)
- [1MYT](https://www.rcsb.org/structure/1MYT)
- [1REX](https://www.rcsb.org/structure/1REX)
- [1RNH](https://www.rcsb.org/structure/1RNH)
- [2LYZ](https://www.rcsb.org/structure/2LYZ)
- [2NRL](https://www.rcsb.org/structure/2NRL)

PDB archive data files are distributed under the
[CC0 1.0 Universal Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).
The original authors and primary citations are recorded in each PDB entry and,
where present, retained in the distributed records.
