# Algorithm Guides

Hikoboshi is a native bioinformatics suite. Its `0.1.0` release exposes the
first alignment surfaces:

- [Pairwise alignment](pairwise.md)
- [Pair-list alignment](pair-list.md)
- [Symmetric all-vs-all enumeration](all-vs-all.md)

These guides describe current public CLI and Python behavior. Database search,
multiple sequence alignment, phylogenetics, clustering, and other suite
surfaces are not part of `0.1.0` yet.
